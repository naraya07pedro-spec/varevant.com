**Agentic Automation Systems Lab — Advanced n8n / AI Systems Engineering | 2026**  
*n8n · JavaScript · APIs · RAG · HITL · Observability · Workflow Reliability*

- Implemented **six reusable n8n/AI engineering contracts** covering effect authorization, bounded async polling, RAG document lifecycle, redacted agent observability, model routing, and parent/child workflow boundaries after synthesizing recurring patterns from a nine-document technical corpus.
- Built **three credential-free n8n reference workflows** and a **24-test Node.js suite** so control logic can be reviewed without vendor accounts.
- Reworked failure-prone workflow patterns into explicit production-style rules: attempt/deadline-bounded polling, classified outcomes, deterministic write authorization, lifecycle-aware retrieval, structured subworkflow contracts, and secret-safe audit events.
- Documented evidence boundaries so source-derived architecture knowledge is separated from personally implemented/tested proof.

## Interview version

“A large part of my n8n work is around the engineering boundaries that break once a workflow becomes real: external effects, uncertain outcomes, long-running jobs, retrieval lifecycle, model/tool boundaries and modular subworkflows. I implemented those concerns as six reusable contracts plus three importable n8n workflow skeletons. The current suite has 24 passing tests and requires no vendor credentials, so a reviewer can inspect the control logic directly.”

## Claims not to use

Do not say:
- “I built all systems from the nine guides.”
- “I deployed the source tutorials to production.”
- “I achieved the performance/cost/accuracy numbers quoted in the guides.”
- “I have production experience with every vendor named in the corpus.”
