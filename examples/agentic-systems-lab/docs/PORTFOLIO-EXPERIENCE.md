# Portfolio experience wording

## Resume-ready entry

**Agentic Automation Systems Lab — Independent Portfolio Engineering | 2026**  
*n8n · JavaScript · APIs · RAG · HITL · Observability · Workflow Reliability*

- Synthesized a nine-document n8n/AI architecture study into **six independently implemented engineering contracts** covering effect authorization, bounded async polling, RAG document lifecycle, redacted agent observability, model routing, and parent/child workflow contracts.
- Built **three credential-free n8n reference workflows** and a **24-test Node.js suite** so control logic can be reviewed without vendor accounts.
- Hardened tutorial patterns by replacing indefinite polling with attempt/deadline bounds, generic retries with outcome classification, implicit multi-agent payloads with explicit schemas, and model-driven writes with deterministic approval gates.
- Documented evidence boundaries so source-derived architecture knowledge is separated from personally implemented/tested proof.

## Interview version

“I studied a broad set of n8n architecture material, but I did not want to list tutorials as experience. I extracted the recurring production patterns and rebuilt the parts that matter most for integration roles as a small testable lab. The result is six reusable contracts and three n8n workflow skeletons around approvals, async polling, RAG lifecycle, observability, model routing, and sub-workflow boundaries. The current suite has 24 passing tests and requires no vendor credentials.”

## Claims not to use

Do not say:
- “I built all systems from the nine guides.”
- “I deployed the source tutorials to production.”
- “I achieved the performance/cost/accuracy numbers quoted in the guides.”
- “I have production experience with every vendor named in the corpus.”
